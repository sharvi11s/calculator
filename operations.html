01

Simple Calculator

Everyday calculations using your keyboard.

Key Action Example
0–9 Enter numbers. 25
+ Addition. 5 + 3
- Subtraction. 9 - 4
* Multiplication. 6 * 3
/ Division. 12 / 4
. Enter decimal numbers. 2.5 + 1.5
( ) Group expressions using parentheses. (2 + 3) * 4
Enter Calculate the result, if keyboard evaluation is enabled. 5 + 3 = 8
Backspace Delete the last character, if supported. 123 → 12
Ctrl + Backspace Clear the display, if supported. Start a new calculation.
02

Engineering Calculator

Shortcuts for scientific functions and expressions.

Key / Shortcut Action Function
r Insert the square-root function. √x
Shift + R Insert the square operation. x²
Shift + 6 Insert the power operator. xʸ
s Insert the sine function. sin
c Insert the cosine function. cos
t Insert the tangent function. tan
l Insert the common logarithm. log
Shift + L Intended shortcut for the natural logarithm; verify current implementation. ln
0–9 Enter numbers in expressions. 2 + 3
+ - * / Enter arithmetic operators. 2 + 3 * 4
( ) Group expressions and function inputs. sin(30)
Backspace Delete the last character, if supported. Edit an expression.
Ctrl + Backspace Clear the display, if supported. Start a new calculation.
