MYCALC MANUAL / FUNCTIONS

Know your functions.

From basic arithmetic to scientific calculations, here's what each function does and how it works.

← Back to Manual
01

Simple Calculator

Everything you need for everyday calculations.

Function What it does Example
+ Addition Adds two or more numbers. 5 + 3 = 8
− Subtraction Finds the difference between numbers. 9 − 4 = 5
× Multiplication Multiplies numbers together. 6 × 3 = 18
÷ Division Divides one number by another. 12 ÷ 4 = 3
( ) Parentheses Groups parts of an expression together. (2 + 3) × 4 = 20
. Decimal Allows calculations with decimal numbers. 2.5 + 1.5 = 4
= Calculate Evaluates the entered expression. 7 + 2 = 9
AC Clear All Clears the current expression. Starts a fresh calculation.
DEL Delete Removes the last entered character. 123 → 12
02

Engineering Calculator

Scientific functions for more advanced mathematics.

Function What it does Example
√x Square Root Finds the number that, when squared, gives the input. √25 = 5
x² Square Multiplies a number by itself. 4² = 16
xʸ Power Raises a number to a specified exponent. 2³ = 8
sin Sine Calculates the sine of an angle. sin(30°) = 0.5
cos Cosine Calculates the cosine of an angle. cos(60°) = 0.5
tan Tangent Calculates the tangent of an angle. tan(45°) = 1
log Common Log Calculates the logarithm with base 10. log(100) = 2
ln Natural Log Calculates the logarithm with base e. ln(e) = 1
n! Factorial Multiplies all positive integers from 1 up to the given integer. 5! = 120
π Pi Represents the mathematical constant pi. π ≈ 3.14159
e Euler's Number Represents the mathematical constant used in natural logarithms. e ≈ 2.71828
a ⇄ b Fraction Conversion Converts a decimal into a fraction or a fraction into a decimal. 0.5 ⇄ 1/2
DEG / RAD Angle Mode Switches trigonometric calculations between degrees and radians. sin(30°) = 0.5
03

Expression Handling

How MyCalc processes mathematical expressions.

Feature What it does Example
Operator Precedence Performs multiplication and division before addition and subtraction. 2 + 3 × 4 = 14
Parentheses Evaluates grouped expressions before surrounding operations. (2 + 3) × 4 = 20
Negative Numbers Handles negative values in expressions. −2 × 3 = −6
Expression Input Allows expressions to be entered and evaluated as a complete calculation. 2 + 3² = 11
