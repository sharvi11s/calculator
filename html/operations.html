Keyboard Shortcuts

Everything you need to calculate faster using your keyboard.

Key / Shortcut Action Example
0–9 Enter numbers. 25
+ Add numbers. 5 + 3
- Subtract numbers or enter a negative number. 5 - 8
* Multiply numbers. 6 * 3
/ Divide numbers. 12 / 4
( ) Group parts of an expression using parentheses. (2 + 3) * 4
. Enter decimal numbers. 2.5 + 1.5
! Enter the factorial operator. 5!
Enter Calculate the current expression. 5 + 3 → 8
Backspace Delete the last character. 123 → 12
Shift + Backspace Clear the display (AC) on the Engineering Calculator. Start a new calculation.
✦

Quick tip

You can also use the calculator's on-screen buttons. Keyboard shortcuts are there to make calculations more convenient.
